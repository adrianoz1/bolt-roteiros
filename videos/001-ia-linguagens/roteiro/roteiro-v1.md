# Linguagem de Programação ainda importa? 

Lembra das antigas disputas entre linguagens de programação?

Sempre tinha o cara que defendia o JAVA 
<samuca>

Ou hater de php
<akita>

mas hoje

O cenário é completamente outro

E talvez, a próxima grande linguagem de programação, 

morra antes mesmo de ficar popular

--

Não pq ela é ruim

Não pq é lenta.

E nem porque os programadores não gostam dela.

Mas simplesmente pq a IA, nem mesmo sabe que ela existe

--

A economia mudou.

E O trabalho de escrever código sempre foi caro.

Mas com os modelos de IA atuais, 

escrever código independente da linguagem de programação ficou muito mais barato,

mas não automático,

não por enquanto pelo menos.

custo não desapareceu.

Ele mudou de lugar.

Antes você pagava um programador para escrever cada linha.

Agora você paga pelos tokens, 

pela infraestrutura, 

pelos testes, 

e pela revisão do dev que vai descobrir por que aquelas quinhentas linhas,

escritas em vinte segundos, não fazem absolutamente nada do que foi pedido.

Escrever código ficou barato.

Ter confiança nesse código ainda não.

--

A grande verdade é que um agente de IA 

não sente prazer com uma abstração elegante,

Ele não participa de uma comunidade. 

Ele não tem carinho pela filosofia da linguagem.

--

Um agente de IA altera o arquivo, 
executa uma ferramenta e precisa receber uma resposta rápida.

No final, a IA não torna a escolha da linguagem irrelevante.

Bem pelo contrário,

agora não basta só perguntar qual linguagem tem a sintaxe mais bonita, 

ou sistema de tipos mais poderoso 

ou a comunidade mais apaixonada pela linguagem

Agora ela também precisa ser compreendida pelos agentes.

Uma linguagem pode ser tecnicamente incrível e continuar invisível para a IA.

Enquanto outra, muito menos elegante, vence simplesmente porque existe documentação suficiente sobre ela.

Isso também não significa que Python e JavaScript vão dominar tudo para sempre.

Uma linguagem nova pode nascer já preparada para esse mundo.

Na minha opinião,
Será aquela que conseguir provar o mais rápido possivel que o código gerado pela IA não é uma completa porcaria, antes de escrever mais 10 mil linhas em 10s

E você, Ainda acha que Liguagem de programação ainda importa?
